# readHD — 3 Months Free Premium Giveaway Webpage

Official promotional landing page for **readHD: ADHD & Focus Reader**, giving away 3 Months of Free Premium access ($19.99 Value) for both **Apple iOS / iPadOS** and **Android (Google Play)**.

## ✨ Features
- **readHD Aesthetic**: Strict adherence to the readHD Utilitarian Charcoal & Focus Mint design system (`#131313`, `#90D883`, Lexend typography, Bionic Prefix Bold Anchoring).
- **Automated Platform Detection**: Automatically detects if the visitor is on an Apple device (iPhone/iPad) or Android, pre-selecting the correct store flow.
- **1-Click Deep Linking**:
  - **Apple App Store**: `https://apps.apple.com/redeem?ctx=offercodes&id=6790681662&code={CODE}` (Directly triggers the native 3-month offer code redemption sheet).
  - **Google Play**: `https://play.google.com/redeem?code={CODE}` (Opens Google Play Store app with the promo code pre-populated).
- **Google Sheets Real-Time Sync**: Connects to Google Apps Script web apps to mark codes as claimed as soon as visitors copy or redeem them.
- **Resilient Fallback**: Graceful local fallback ensures zero disruption even during network latency or permission checks.
- **Lightweight & High-Performance**: 100% static client-side web application suitable for free hosting on **GitHub Pages**.

## 🚀 GitHub Pages Setup
1. Go to your repository on GitHub: `https://github.com/Mawallil/readhd-promo-codes`
2. Click **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your giveaway website will be live in ~1 minute at:
   `https://mawallil.github.io/readhd-promo-codes/`
